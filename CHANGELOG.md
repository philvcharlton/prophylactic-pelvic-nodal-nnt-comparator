# Changelog

## 1.4.0 — 2026-10-22

- Refactored NNT/NNH arithmetic into an independently testable JavaScript module.
- Added structured POP-RT and SPPORT trial data.
- Added risk-difference confidence-interval handling and explicit zero-crossing behavior.
- Documented why hazard-ratio confidence intervals are not converted into NNT intervals.
- Added automated tests, citation metadata, licences, contribution guidance and manuscript draft.
- Preserved the v1.3.0 clinical interface and strengthened research-use limitations.

## 1.3.0 — 2026-09-28

- Renamed the application NNT Comparator.
- Added definitive and salvage prostate radiotherapy comparisons, toxicity and 2026 SPPORT quality-of-life evidence.
